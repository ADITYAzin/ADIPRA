### Project Tech Stack Specification
- **Framework:** Astro (with React integration)
- **Language:** JavaScript (ES6+ / JSX)
- **Styling:** Tailwind CSS
- **UI Library:** shadcn/ui (JavaScript / JSX version)
- **Animation:** Framer Motion / Motion + Lenis (Smooth Scrolling)
- **Icons:** Lucide React
- **Objective:** Build a high-performance, visually-focused creative portfolio with modern aesthetics, Bento grid showcases, smooth micro-interactions, and fast load times using pure JavaScript.
